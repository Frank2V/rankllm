# RankLLM

大模型排行榜：**<https://rankllm.pages.dev>**

LLM leaderboard: expert rankings and crowd votes, side by side.

同一个模型，两套名次。

**专家榜**照搬 Artificial Analysis 智能指数、BenchLM 这类公开评测的原始名次，不重排、不加权。**大众榜**由进站的人投票和写评价形成，样本少时向全体均值收缩。

两套名次并排，落差本身就是信息：要么评测漏了什么，要么用过的人不买账。

## 有什么

- **公开榜速览**：SuperCLUE、OpenCompass 司南、BenchLM 等 6 张榜的原始名次，标注快照日期
- **模型目录**：819 个模型按厂商分组，点进去看它在各榜的位置和使用评价
- **评测集收录**：464 个评测集的类别、是否计入评分、活跃度和官方链接
- **投票与评价**：不用注册；用途支持自填；评价数太少时均分做了收缩，别当真

## 边界，先说清楚

- 分数是抓取那一刻的快照，会过期，抓取日期写在每张表上
- 各家分数口径不同，跨榜不可比，没收录的格子留「—」不猜
- 投票做了设备 + IP 双配额，换 IP 的有组织刷票挡不住，样本少时评价均分别当真
